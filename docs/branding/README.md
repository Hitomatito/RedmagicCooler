# Logo de RedmagicCooler

Marca **E1 · Anillo**: ventilador de cinco palas asimétricas dentro de una carcasa RGB,
con buje mecánico y halo grafito. Es un símbolo original; no reutiliza el logo de RedMagic.

## Archivos

- `logo-e1.svg`: fuente vectorial, 512 × 512.
- `logo-e1.png`: previsualización, 512 × 512.

## Paleta

| Uso | Color |
|---|---|
| Fondo grafito (centro) | `#1B2433` |
| Fondo grafito (medio) | `#0C1118` |
| Fondo grafito (borde) | `#06090D` |
| Blanco de palas | `#F4F7FF` |
| Cian | `#4FE3FF` |
| Violeta | `#7C5CFF` |
| Magenta | `#FF4FD8` |

## Integración Android

- Icono adaptativo: `app/src/main/res/drawable/ic_launcher_foreground.xml`
- Fondo adaptativo: `app/src/main/res/drawable/ic_launcher_background.xml`
- Capa monocroma: `app/src/main/res/drawable/ic_launcher_monochrome.xml`
- Splash: `app/src/main/res/drawable/ic_splash_logo.xml`
- Iconos legacy: `app/src/main/res/mipmap-*/ic_launcher*.png`

El contenido del icono adaptativo queda dentro de la zona segura de 66 dp. Los iconos
legacy usan una versión ampliada del ventilador para que no se vea pequeño en el launcher.
